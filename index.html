PyPath: Learn Python

Real Python, step by step, on iPhone and iPad.

PyPath teaches you to program in Python with 65 short lessons in 13 chapters, from your first print() to classes, generators and the standard library. Every lesson ends with a challenge that PyPath checks for you, and every line you write runs on the official CPython 3.15 interpreter, built into the app. It works offline and has no ads, accounts or tracking.

Support

Found a problem or have a question? Please open an issue on GitHub and describe what happened, including the lesson name if it's about a lesson. You'll need a free GitHub account.

Common questions

Is it real Python? Yes. PyPath includes CPython 3.15, the same Python you'd install on a computer, with its standard library. A few parts that need a desktop, such as turtle and tkinter, aren't available on iPhone and iPad, and packages from pip can't be installed.

My program never ends. Tap Stop. Loops whose condition never becomes false run forever, in any language.

How do I answer input()? When a program asks a question, a text box appears under the output. Type your answer and tap the send button.

Where are files my programs create? In PyPath's own folder on your device. import os then print(os.listdir()) lists them.

Can I start the course again? Yes: About → Reset course progress. Your Playground programs are kept.

Does PyPath work without internet? Yes, completely.
